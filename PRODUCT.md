# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Два игрока Motorsport Manager в одной LAN-сессии. Первый управляет карьерой в игре Host; второй следит за своей машиной и управляет ею во время Practice, Qualifying и Race через отдельный Windows-пульт.

## Product Purpose

Race Command превращает одиночную игру в совместный pit-wall workflow: Host остаётся авторитетным симулятором, а второй игрок получает телеметрию и безопасные команды своего пилота.

## Positioning

Пульт не копирует всю игру и не запускает второй Unity-клиент. Он передаёт целевые команды в единственную авторитетную сессию и показывает состояние непосредственно из игровых объектов.

## Operating Context

Пульт используется рядом с Motorsport Manager во время живой сессии. Ключевые задачи: быстро прочитать время, позицию, дельты и состояние машины; оценить setup; выбрать программу, шины и режимы; отправить машину на трассу или в боксы.

## Capabilities and Constraints

- Windows Forms на .NET 8; игра работает на старом Unity/Mono.
- LAN TCP, Host по умолчанию `127.0.0.1:27153`.
- Host авторитетен; клиент управляет только выбранным пилотом.
- Телеметрия может отсутствовать до входа Host в сессию.
- Изменение Unity DLL требует перезапуска Host; лаунчер обновляется отдельно.

## Brand Commitments

Название Race Command / Pit Wall. Интерфейс должен ощущаться как серьёзный инженерный инструмент F1, а не как декоративный игровой HUD.

## Evidence on Hand

Живой Host, реальные игровые сейвы, декомпилированные игровые интерфейсы и автоматические LAN/smoke-тесты находятся в репозитории.

## Product Principles

- Реальное состояние важнее оптимистичной индикации команды.
- Сначала читается сессия и машина, затем отправляется действие.
- Никаких вымышленных метрик: отсутствующие данные показываются как недоступные.
- Частые команды доступны в один шаг и подтверждаются телеметрией.
